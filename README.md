# Avani Runs to Mani

A lightweight, self-contained birthday-site feature built with HTML, CSS, SVG, and JavaScript. No build step or 3D engine is required.

## Open the project

Open `index.html` in a modern browser. The reunion scene moves horizontally as you scroll and plays a short run-and-hug animation when it reaches the center. The proposal appears after the love note.

## Files

- `index.html` — reunion section and proposal scene
- `style.css` — responsive layout, character motion, and reduced-motion support
- `script.js` — scroll timing, celebration, answer persistence, and replay controls
- `assets/couple-photo.jpeg` — couple photograph used in the forever screen
- `assets/avani-teal-outfit.jpeg` — outfit reference
- `assets/four-moments-reference.png` — supplied chibi illustration reference

The proposal choice is stored only in this browser’s local storage. It is not sent anywhere.
